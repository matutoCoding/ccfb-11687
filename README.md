# 光伏阵列阴影与眩光分析系统

浏览器端光伏阵列阴影 / 眩光分析工具,TypeScript + three.js,数据全部保存在本地浏览器,无需服务器。

## 启动

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 生产构建到 dist/
npm run verify     # 精度与性能验证(无需浏览器)
```

## 功能

| 页面 | 功能 |
|------|------|
| 项目列表 | 项目增删改、复制,localStorage 持久化,JSON 导出/导入 |
| 场地建模 | 摆放厂房(长方体)/树木(球冠)/电线杆(圆柱),拖拽移动、尺寸可改 |
| 阵列布置 | 倾角、方位角、行距、排数、每排组件数批量布置,整片拖动;一键计算冬至 9:00–15:00 不遮挡最小行距 |
| 阴影分析 | 任意日期时刻太阳位置 + GPU 实时阴影;全年逐时(步长可调)每组件遮挡比例,热力图 + CSV 导出 |
| 眩光分析 | 可拖动观察点,全年逐时扫描组件镜面反射,输出眩光时刻表 CSV |
| 设置 | 经纬度/时区、分析年份、时间步长、采样密度、眩光判定角 |

## 计算模型与精度

- **太阳位置**:NOAA 公式(精度约 0.01°),`src/solar/sun.ts`
- **排间遮挡**:闭式解(前排上沿阴影线与后排坡面求交),`src/solar/geometry.ts`
- **障碍物遮挡**:每个采样点建立"方位角→遮挡高度角"轮廓(1° 分辨率),逐时步查表,`src/solar/horizon.ts`
- **全年分析**:时间加权 + 辐照加权(入射角余弦)两种遮挡比例,`src/solar/shading.ts`
- **眩光**:反射向量 r = 2(s·n)n − s,与观察方向夹角小于阈值判定,`src/solar/glare.ts`

`npm run verify` 的验证结果(2025 数据):

- 二分二至正午高度角与理论值偏差 < 0.1°
- 单杆影长 vs 三角函数手算:相对误差 0.0000%(要求 < 1%)
- 排间遮挡闭式解 vs 独立射线求交采样:最大偏差 0.73%
- 冬至最小行距:采用后 9–15 点逐分钟复查零遮挡,减 5cm 即出现遮挡
- **1000 块组件 × 4395 个日照时步 × 16 采样点:约 1 秒**(要求 < 20 秒)

## 坐标与角度约定

- 坐标系:x = 东,y = 北,z = 天,单位米
- 方位角:0° = 正南,正值偏西,负值偏东(与 PVsyst 一致)
- 时间为项目所在时区的当地时间

  store.ts          项目存储(localStorage + 导入导出)
  solar/sun.ts      太阳位置
