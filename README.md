# 光伏阵列阴影与眩光分析系统

浏览器端三维光伏电站设计与分析工具,纯 TypeScript + three.js + Vite 构建,
数据保存在浏览器 localStorage,全年分析在 Web Worker 中运行。

## 功能与页面

| 页面 | 能力 |
| --- | --- |
| 项目列表 | 项目增删改查、复制、JSON 导入导出,全部存 localStorage |
| 场地建模 | 厂房/电线杆/树木三类遮挡物,位置与尺寸可精确编辑,三维点选 |
| 阵列布置 | 倾角、方位角、行距、列距、行列数批量布置;整片阵列平移;冬至最小行距自动计算 |
| 阴影分析 | 任意日期时刻实时地面/组件阴影;全年逐时遮挡比例热力图;遮挡损失 CSV |
| 眩光分析 | 观察点管理;全年反射眩光时刻表;视线遮挡标记;眩光 CSV |
| 设置 | 眩光锥角、栅格分辨率、时间步长、折射/视线检测开关 |

## 计算引擎(`src/engine/`,与渲染完全解耦,可独立测试)

- **solar.ts** — NOAA 太阳位置算法(赤经赤纬、地球轨道偏心率、时差、真太阳时),
  输出高度角、方位角(北 0 顺时针)与 ENU 单位向量。
- **geometry.ts** — 2D 向量、凸包、Sutherland-Hodgman 凸多边形裁剪、多边形面积、栅格求并。
- **casters.ts** — 厂房/杆/树/组件排的平行光投影剪影;电线杆用解析胶囊阴影。
- **layout.ts** — 阵列展开为每块组件的三维位姿(局部坐标架 u/vUp/法线)。
- **shadow.ts** — 逐组件遮挡比例:空间粗筛 + 平面投影裁剪,解析面积比;
  排级自遮挡按排广播;可复用 `ShadingContext` 降低全年分析开销。
- **rowspacing.ts** — 冬至 9–15 点最小行距,复用阴影内核二分求解,并给三角公式对照。
- **glare.ts** — 镜面反射向量与观察视线夹角判定,含柱体视线遮挡检测。
- **annual.ts** — 全年逐时聚合,输出每组件全年与 12 个月平均遮挡比例。
- **csv.ts** — 带 UTF-8 BOM 的遮挡损失与眩光时刻表 CSV。

## 精度与性能(见 `tests/`)

- 单杆影长与 `h/tan(α)` 三角公式同源,相对误差 < 1e-12(验收线 1%)。
- 太阳位置覆盖二至、正午、上下午对称、夜间等特例,方位角四象限正确。
- 行距 3D 模型与三角公式逐时刻吻合(差异 < 2%)。
- 1000 块组件全年 8760 时间步分析约 20s(单时刻 ~2ms),在 Worker 内不阻塞 UI。

```bash
npm install
npm run dev        # 开发服务器
npm run test       # 47 个单元/集成/UI 测试
npm run build      # 类型检查 + 生产构建
npm run perf       # 性能专项
```

## 坐标约定

ENU 右手系:x 朝东、y 朝北、z 朝天;方位角正北为 0°、顺时针增加;
水平组件倾角 0°,正南朝向方位角 180°。
